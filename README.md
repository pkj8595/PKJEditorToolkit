# Tyranno Editor Toolkit

Small, focused workflow tools for the Unity Editor.

## Features

- Move a component from one scene GameObject to another by dragging its Inspector header onto the target Hierarchy row.
- Restore the move with a single Undo operation.
- Navigate Inspector selection history with the mouse Back and Forward buttons.
- Open eight project folders with configurable Numpad shortcuts.
- Find missing scripts and broken serialized references in open scenes or selected prefabs.

## Installation

Open `Window > Package Manager`, select **Install package from git URL**, and enter:

```text
https://github.com/DarknessTyranno/TyrannoEditorToolkit.git?path=/Packages/io.github.darknesstyranno.editor-toolkit
```

## Requirements

- Unity 6 or newer

# Changelog

## [0.1.0] - Unreleased

### Added

- Component Mover for dragging a component from the Inspector onto another scene GameObject in the Hierarchy.
- Single-step Undo support for component moves.
- Inspector selection history navigation with the mouse Back and Forward buttons.
- Eight project-specific folder shortcut slots with configurable open and save bindings.
- Missing script and serialized object reference scanning for open scenes and selected prefabs.
